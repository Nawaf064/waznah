# وزنة | Waznah

تطبيق أكاديمي لمساعدة مالكي المركبات على مقارنة أسعار قطع الغيار المتاحة، واستكشاف ورش غرب الرياض، وتنظيم احتياجات الصيانة وتقدير تكلفتها.

## فكرة المشروع

يجمع وزنة معلومات القطع والخدمات والورش في واجهة عربية تدعم عرض أسماء المنتجات والقوائم بالإنجليزية. يهدف إلى تسهيل الوصول للمعلومات ودعم قرار الصيانة، مع توضيح مصدر السعر وحدود التوافق والتوفر.

## المميزات

- البحث عن قطع الغيار وتصفية النتائج حسب القسم وبيانات السيارة وترتيب الأسعار.
- عرض عروض الموردين وروابط مصادرها، مع التمييز بين السعر المعروف والسعر الذي يحتاج تأكيدًا.
- استكشاف الورش وعناوينها وروابط الخرائط والاتصال.
- عرض أجور خدمات الصيانة وأسعار البداية والنطاقات المتاحة.
- حفظ المفضلة والسيارة وقائمة الصيانة وحساب مجموع أسعار القطع المعروفة.
- حسابات Firebase: الدخول والتسجيل وتأكيد البريد واستعادة كلمة المرور وحفظ بيانات المستخدم.
- وضع ضيف ببيانات محلية منفصلة عن الحساب.
- تصميم مستوحى من iOS بألوان الأسود والفضي والكحلي، ومقدمة متحركة ورمز الريال السعودي الرسمي.

## التقنيات

Flutter وDart للواجهة والمنطق، Firebase Authentication للحسابات، Cloud Firestore للبيانات السحابية، وCupertino لعناصر الواجهة. يحتوي الكتالوج المرفق على 13 قطعة وورشتين و6 خدمات؛ قد تختلف النسخة السحابية بعد تحديثها.

## التشغيل السريع

يتطلب المشروع Flutter يتضمن Dart 3.13.3 أو إصدارًا متوافقًا مع pubspec.yaml، وAndroid Studio مع Android SDK ومحاكي Android. ملفات التشغيل مهيأة لأندرويد؛ تصميم iOS لا يعني أن إصدار iPhone اختُبر أو نُشر.

```sh
flutter pub get
flutter devices
flutter run -d <ANDROID_DEVICE_ID> -t lib/demo.dart
```

استبدل `<ANDROID_DEVICE_ID>` بمعرف الجهاز الظاهر في `flutter devices`، مثل `emulator-5554`. مدخل `demo.dart` يشغّل العرض الأكاديمي كضيف دون حساب سحابي. يمكن تصفح الكتالوج وحفظ المفضلة وقائمة الصيانة محليًا. فتح المصادر والخرائط يحتاج اتصالًا وتطبيقًا مناسبًا.

إذا كان ملف `lib/firebase_options.dart` غير موجود، انسخ `lib/firebase_options.example.dart` إلى هذا الاسم قبل التشغيل. نسخة التسليم تحتوي إعدادات تجريبية لا تمنح اتصالًا بقاعدة الإنتاج.

لتشغيل الحسابات الحقيقية، جهّز مشروع Firebase الخاص بك حسب [دليل التشغيل والتثبيت](docs/DEPLOYMENT.md)، ثم شغّل `lib/main.dart`.

## بنية المشروع

```text
lib/          واجهات التطبيق والمنطق والحفظ والاتصال السحابي
assets/       الخط العربي ورمز الريال ومعلومات مصادرهما
android/      إعدادات تطبيق أندرويد
ios/         هيكل منصة iOS؛ غير مختبر فعليًا
web/          ملفات منصة الويب؛ لا يوجد موقع منشور ضمن التسليم
data/         مسودة الكتالوج المنظم
test/        اختبارات التطبيق
tool/        أدوات التحقق من الكتالوج وإدارته واختبار قواعد البيانات
docs/        شرح الموارد والتشغيل وملف التحليل والتصميم
```

## التحقق

```sh
flutter analyze
flutter test
flutter build apk --debug -t lib/demo.dart
```

تغطي الاختبارات البحث والتصفية والمفضلة والصيانة وتنسيق الأسعار والواجهة الضيقة ومقدمة التشغيل وحالات فشل الحفظ. توجد اختبارات مستقلة لمحاكيات Firebase في [دليل الإدارة](tool/admin/README.md). نجاح الاختبارات المحلية لا يثبت توفر المصادر الخارجية أو وصول البريد الحقيقي.

## البيانات والحدود

الأسعار معلومات منشورة وليست أسعارًا مباشرة أو ضمانًا للتوفر أو التوافق. قد تمثل بعض خدمات الصيانة أسعار بداية وليست حدًا نهائيًا للفاتورة. يجب تأكيد السعر والقطعة والخدمة مع المورد أو الورشة. راجع [مصادر البيانات](sources.md).

لا ينفذ التطبيق شراءً أو حجزًا أو دفعًا إلكترونيًا. الحفظ السحابي يحتاج اتصالًا؛ بيانات الضيف تبقى على جهازه ولا تنتقل تلقائيًا إلى الحساب. لا يتضمن المستودع حسابات مستخدمين أو كلمات مرور أو صلاحيات إدارة سحابية.

## الموارد الخارجية

الخط العربي Noto Sans Arabic مرفق مع ترخيصه في `assets/fonts/OFL.txt`. رمز الريال من البنك المركزي السعودي ومصدره موثق في `assets/currency/SOURCE.md`. حقوق الموارد الخارجية تعود لأصحابها.
